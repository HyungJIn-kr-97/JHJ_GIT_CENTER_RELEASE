# JHJ Git Center — Privacy Policy

Last updated: 2026-10-20 · Publisher: JHJ Technologies

JHJ Git Center does not collect personal data and does not send any data to the developer.

- **What the app reads (on this PC only):** the git repositories you add, the repository list of GitHub Desktop, and the account names of git and GitHub CLI (including the commit author name and e-mail in your git settings). Passwords and tokens are never read.
- **Network:** the app connects to remote repositories only when you click Fetch, Pull, Push or a similar button, through git and GitHub CLI. Checking for a new version reads the public release list of this repository (the Microsoft Store version leaves updates to the Store).
- **Storage:** settings, activity history and logs are stored only in `%LOCALAPPDATA%\JHJ_Git-Center` on your PC.
- **Error reports:** only when you click "Report an issue", a report is copied to your clipboard and the GitHub issue page opens. Repository paths and remote addresses are masked. Nothing is sent automatically.

# JHJ Git Center 개인정보처리방침

최종 수정일: 2026-10-20 · 게시자: JHJ Technologies

JHJ Git Center 는 개인정보를 수집하지 않으며, 제작자에게 어떤 정보도 보내지 않습니다.

- **앱이 읽는 것(이 PC 안에서만):** 사용자가 등록한 git 저장소, GitHub Desktop 의 저장소 목록, git · GitHub CLI 계정 이름(git 설정의 커밋 작성자 이름·메일 포함). 비밀번호와 토큰은 읽지 않습니다.
- **네트워크:** 사용자가 Fetch · Pull · Push 등을 누를 때만 git 과 GitHub CLI 가 원격 저장소에 접속합니다. 새 버전 확인은 이 저장소의 공개 릴리스 목록을 읽습니다(Microsoft Store 판은 업데이트를 Store 에 맡깁니다).
- **저장:** 설정 · 작업 기록 · 로그는 이 PC 의 `%LOCALAPPDATA%\JHJ_Git-Center` 에만 저장됩니다.
- **오류 보고:** 사용자가 「오류 보고」를 누를 때만 보고서를 클립보드에 복사하고 GitHub 이슈 화면을 엽니다. 저장소 경로와 원격 주소는 가립니다. 자동으로 보내는 것은 없습니다.
