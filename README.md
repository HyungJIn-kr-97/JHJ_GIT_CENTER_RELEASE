# JHJ Git Center — 배포판

**JHJ Git 통합 관리 센터**의 설치 파일만 올리는 저장소입니다. 여러 git 저장소를 한 화면에서 보고, 골라서 한꺼번에 받고 올리는 Windows 데스크톱 앱입니다. 소스는 비공개 저장소에 있습니다.

## 설치

[Releases](https://github.com/HyungJIn-kr-97/JHJ_GIT_CENTER_RELEASE/releases/latest) 에서 `JHJ_Git-Center_Setup.exe` 를 받아 실행합니다. 설치 화면이 Git · GitHub CLI 가 없으면 함께 설치합니다.

최신 설치 파일 주소(늘 같은 주소)입니다.

```
https://github.com/HyungJIn-kr-97/JHJ_GIT_CENTER_RELEASE/releases/latest/download/JHJ_Git-Center_Setup.exe
```

- Windows 10/11 x64 전용입니다.
- 처음 실행할 때 SmartScreen 창이 뜨면 「추가 정보」 → 「실행」을 누릅니다. 코드 서명이 없어서 뜨는 창입니다.
- 설치본은 이 저장소의 최신 릴리스를 보고 스스로 업데이트합니다.
- 파일마다 `.sha256` 이 함께 올라가 있습니다.
- 문제는 [이슈](https://github.com/HyungJIn-kr-97/JHJ_GIT_CENTER_RELEASE/issues/new)로 남겨 주십시오.
